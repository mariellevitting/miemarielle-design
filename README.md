# miemarielle design

Porteføljeside: ren HTML og CSS, ingen byggesteg.

- `index.html` – innhold (prosjekter, om meg, kontakt)
- `style.css` – utseende
- `bilder/` – prosjektbilder

Forhåndsvis lokalt: `python3 -m http.server` i mappen, og åpne http://localhost:8000.

Publisering: last opp mappen til Netlify Drop, eller push til GitHub og slå på GitHub Pages.
